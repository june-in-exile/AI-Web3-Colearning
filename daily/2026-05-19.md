## Day 1 安全教训（写进 proof-of-work）

第一次创建 bot 时直接把 BotFather 给的 token 贴到了 agent 聊天框，agent 立刻提醒并要求 `/revoke`。这印证了 Bootcamp Week 1 模块 A 的 guardrail 原则：

- **AI Agent 不应直接接触 secret**（私钥 / 助记词 / bot token / API key）
- **secret 流转必须经过人工 + 工具的"非聊天"通道**（向导式 CLI、本地 .env、密码管理器）
- 之后所有 secret 配置改走 `hermes setup gateway` interactive prompt 或直接编辑 `~/.hermes/.env`
- 切换次要机也是安全分层的应用：blast radius 越小越好
